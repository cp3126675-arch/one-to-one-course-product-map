# 一对一课程产品研发总图

用于梳理一对一课程产品的设计问题，以及在讨论中定位问题、方案、研制方法与验证依据。

## 产品设计主线

产品定位 → 价值与画面 → 产品方案 → 课程与交付 → 样板与评价 → 复用与持续。

AI制作与生产资料沉淀伴随每次样板制作，不是独立的后期阶段。会议中的价值研究、验证方法、外部工作与产品需求分别处理。

## 文件

- `index.html`：可独立运行的交互研发总图，无后端、无API密钥、无外部脚本依赖。
- `.nojekyll`：按静态文件发布。

本仓库只维护研发总图，不含学生档案、试卷、作业、会议原件或访问凭据。

## 访问方式

仓库保持私有，不启用公开网站。仅仓库所有者与已授权成员可访问。

GitHub文件页显示HTML源码；交互图由浏览器运行`index.html`，可以离线使用。
